### 📄 [RAG Document Q&A](https://github.com/nishant-netizen524/Rag-document-qa)

A citation-grounded PDF question answering system built with Python, FAISS, SQLite, Streamlit, and OpenRouter.

**Features:**
- Upload PDF documents
- Ask natural language questions
- Retrieve relevant chunks using FAISS
- Generate answers with page-level citations
- Optional reranking for improved relevance
- Evaluation script for testing answer quality

**Tech Stack:** Python · Streamlit · FAISS · SQLite · OpenRouter · RAG
